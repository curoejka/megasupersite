# Проект "PizzaHub" 🍕

![Фото участника](img/IS24A_Chernyshev_AA.jpg "Чернышев Артём Алексеевич")

## Описание программы

Данный проект представляет собой веб-сайт для заказа пиццы. Основная цель — предоставить пользователю **удобный** интерфейс для выбора *вкусной* пиццы. ~~Ранее функционал был ограничен~~, но теперь проект активно развивается! 🚀

### Необходимые условия

Для работы с проектом потребуется установленный **Git** и современный веб-браузер. 💻

```bash
# Проверка наличия Git
git --version
```

### Установка

Чтобы развернуть проект локально, выполните следующие шаги:

```bash
git clone https://github.com/curoejka/megasupersite.git
cd megasupersite
```
